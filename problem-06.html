My Programming Notes

Welcome to my programming notes. Here are some basic notes about JavaScript, Java, and Python.

JavaScript

JavaScript is a programming language mainly used to make web pages interactive and dynamic.

Important concept: JavaScript can be used to add actions and interactions to websites. 


let name = "Abhi";
console.log("Hello " + name);

Java

Java is a general-purpose programming language used for web applications, mobile applications, and software development.

Important concept: Java follows object-oriented programming concepts. 


public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Python

Python is a simple and powerful programming language used in web development, data science, artificial intelligence, and machine learning.

Important concept: Python is known for its simple and easy-to-read syntax. 


name = "Abhi"
print("Hello", name)

Quick Revision

JavaScript: Used mainly for interactive websites.

Java: Used for applications and software development.

Python: Used for AI, ML, data science, and web development.
